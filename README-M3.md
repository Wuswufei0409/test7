# M3 生存核心、昼夜与农耕

MUL-39 在 M1 浏览器玩法基线上增加了可持久化、可确定性测试的生存闭环。

## 操作

- `H` 食用当前选中的面包、胡萝卜或马铃薯。
- `D` 在和平/简单/普通/困难之间切换；敌怪伤害和生命随难度变化，和平会清除敌怪。
- `J` 模拟敌对生物攻击；`K` 测试死亡掉落；`P` 在床/世界出生点重生。
- `N` 快进半天；夜间按 `B` 睡床，跳到清晨并设置重生点。
- 对准草方块/泥土按 `T` 开垦，对准耕地并选中种子、胡萝卜或马铃薯后按 `G` 播种；`R` 推进一次生长 tick，成熟后按 `G` 收获。
- 新世界的背包末排提供基础食物、三种种植物、木锄与床，可用 `E` 打开背包并移到快捷栏。

世界右上角面板实时显示难度、生命/饥饿、昼夜时间、敌怪和作物数量。夜间敌怪以绿色实体显示，日照下亡灵燃烧变橙；作物按生长阶段增高。

## 验证

```bash
npm test
npm run build
npm run evidence-gameplay
npm run evidence-m3
```

`evidence/m3_gameplay.json` 是浏览器实跑的结构化结果；四张 `m3_*.png` 分别覆盖伤害/食物、夜间刷怪、睡床/日照燃烧、成熟农田。
